# 宿主核心稳定出口

2026-09-26，`feat/resident-macos-app`。本出口包括 TS 宿主运行管理、契约与持久注意事项、同来源 CLI/TUI 接入及必要回归；原生外观、系统通知、登录项和发行包仍是独立待验工作，不据此宣布完整 App 验收。

## 定向事实

主线最后一轮定向检查为 **10 pass / 0 fail / 1096 断言**，类型检查退出码 0。覆盖 `resident-manager`、`resident-reclaim-order`、`host-runtime`、`native-backpressure`、`process-time` 五个文件。

- 真实执行者先断 socket 时 PID 仍存活，该代仍在 manager 登记，停止结果不报 done；实际 onExit 后自有组仍存活，也不能报 done；自有组经过 KILL 确认退出后才返回 done。
- 同 session 再次输入创建后继代，旧代重复退出回调不能移除后继代，也不能提前兑现它的停止。停止等待者以 RunRecord 为键，执行者代次、输入停止版本与协作 execution token 各有其身份用途，见接入契约。
- 反向装置只在 Bun 模块加载内存里恢复“socket close 即 retire”，同一真实进程测试 **0 pass / 1 fail**，精确失败于“PID 仍活但该代已从登记移除”，约 272ms，不依赖超时；未改生产源文件。
- 持久关闭准入首次抛错，重试必须再过该门；扩展 shutdown 挂起期间真实执行者仍会 TERM/KILL，但 waitUntilExit 不伪报完成。
- host.shutdown 和生命管道 EOF 分别走真实 helper 进程，确认 host.stopped 后实际退出；这两项是空闲宿主，待答与实际模型/工具链另见核心执行者和原生验证。
- 56 条真实用户、助手、工具历史跨 50/6 分块，次序完整、无漏重，零执行者、零模型/工具调用，事项保持未读。
- 停止版本检查防旧菜单停同一执行者的新输入；慢原生观察者保留完整已开始帧和控制回复；真实进程身份查询不随 TZ 改变。
- 暂存质量门后的独立身份审查复现原生投影竞态：异步目录查询返回旧运行状态，却带后继代停止版本。`native-projection.test.ts` 用真实记录读口在查询中换代，修前明确得到 gen=2 而预期 gen=1；修复在查询前同步固定版本，沿用原接口，无新增持久状态。

主线日志、正反向真实次序 JSON、反向加载脚本及初次全量红现场已复制到规划材料库 `Magic Code/验证/常驻App与状态栏/core/`，manifest 记录原路径与 SHA-256；原件保留。初次全量 **2901 pass / 39 fail** 是装置适配与诊断缺口的发现现场，不能当作最终质量门。
